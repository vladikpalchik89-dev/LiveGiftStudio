# LiveGiftStudio

Приложение для стримеров: показывает оверлей с подарками, донатами и подписками
из TikTok LIVE и DonationAlerts прямо поверх других приложений на Android.

Состоит из двух частей:

| Часть | Где | Что делает |
|---|---|---|
| Android-приложение | `app/` | Оверлей, звуки, анимации, настройки. Java, без XML-лейаутов |
| Сервер | `server.js` | Подключается к TikTok LIVE и DonationAlerts, раздаёт события по WebSocket |

## Что умеет

- 🎁 **Оверлей подарков** из TikTok LIVE: анимация, звук и озвучка имени дарителя.
- 💰 **Донаты** из DonationAlerts и со Сбера: сумма в цель сбора, звук и TTS.
- 👋 **Подписки и чат**: отдельные звуки, озвучка сообщений с ограничением очереди.
- 🏦 **Донаты со Сбера** через разрешение на уведомления — без банковского API.
- 📸 **«Донатер дня»**: журнал донатов, быстрый переход в профиль TikTok и подпись для сторис.
- 🎯 **Виджеты** цели сбора, лайков и топа донатеров поверх экрана.
- 🔊 **Редактор звуков и голосов**: назначай свои WAV-файлы и голоса TTS на каждое событие.
- 🔄 **Автореконнект** WebSocket с растущей паузой и ручное переключение аккаунта стримера.
- 🎛 **Пульт в уведомлении**: тестовый донат/подарок, рестарт WebSocket и «выключить TTS на 5 минут».
- 📜 **Лог событий эфира**: фильтр по донатам/подаркам/чату/подпискам и экспорт в CSV или JSON.
- 📊 **Отчёт об эфире**: сумма и топ-5 донатеров, пик активности, счётчики подарков/подписок/чата, копирование в буфер.
- 🛡 **Failover DonationAlerts**: опрос каждые 15 секунд включается, только если WebSocket молчит больше минуты.
- 🧪 **Тестовые события** `/test-gift`, `/test-donation`, `/test-follow`, `/test-chat` — проверять оверлей без реального эфира.

## Как это работает

```
TikTok LIVE ──┐
              ├─► server.js (Render) ──WebSocket──► OverlayService (Android) ──► оверлей + звук
DonationAlerts┘
```

Приложение подключается к `wss://<сервер>/events` и получает JSON-события:
`gift`, `donation`, `follow`, `chat`, `stream_end`, `connected`.

## Донаты со СберБанка

Входящий перевод на карту Сбера превращается в донат: оверлей, звук,
озвучка и сумма в цели сбора.

У Сбера нет публичного API для физлиц, поэтому приложение читает
push-уведомления СберБанка. Нужно один раз выдать разрешение:

**Настройки → Приложения → Специальный доступ → Доступ к уведомлениям →
LiveGiftStudio → «Разрешить»**

В приложении: раздел **🏦 СБЕРБАНК → Донаты со Сбера**.

| Настройка | Что делает |
|---|---|
| «Показывать донаты со Сбера» | включить/выключить источник |
| «Только входящие» | отсекает списания, оплаты и покупки |
| «Минимальная сумма» | игнорировать переводы мельче N ₽ |

Работает, пока запущен оверлей. Донат озвучивается тем же голосом и
показывается с тем же звуком, что назначен на DonationAlerts.

## Донатер дня (сторис в TikTok)

Каждый донат — со Сбера или DonationAlerts — автоматически попадает в
журнал: сумма, имя, комментарий, время. Журнал нужен, чтобы после эфира
за 2 минуты собрать историю про донатера.

**Приложение → 🏦 СБЕРБАНК → 📸 Донатер дня.** Тап по записи открывает:
указать `@ник`, открыть профиль в TikTok, скопировать подпись для сторис.

Из уведомления Сбера TikTok-ник не приходит (только имя из банка), поэтому
схема такая:

> Донатер пишет свой `@` в комментарии к переводу, но само уведомление Сбера
> его не содержит — поэтому ник в журнале нужно указать вручную, тапом по записи.
> После этого профиль открывается одним тапом.

Для DonationAlerts `@` из комментария подхватывается сам.

Готовая рамка 1080×1920 для сторис лежит в
`~/Android/LiveGiftStudio-devnotes/story/` (и в
`Pictures/LiveGiftStudio/` на телефоне): прозрачный центр под видео
донатера, неоновая обводка в цветах приложения. Инструкция по CapCut —
`story/README.md`.

## Сборка APK

Сборка идёт только через GitHub Actions — локально Android SDK не нужен.

1. Запушь изменения в `main` (или запусти workflow вручную: **Actions → Build APK → Run workflow**).
2. Дождись зелёной галочки.
3. Скачай APK в **Releases** репозитория: сборка публикуется как `build-N`,
   файл называется `app-debug.apk`. Ссылка есть и внизу страницы запуска Actions.

### Секреты сборки

Ключи сервера **больше не встраиваются в APK**. После установки зайди в
**⚙️ НАСТРОЙКИ → 🔐 Ключи доступа** и введи те же значения, что заданы на сервере:

| Ключ | Для чего |
|---|---|
| Ключ переключения аккаунта | заголовок `x-switch-key` для `/switch-account`, `/reconnect` и тестовых событий |
| Ключ заказов | отправка заказов в Google Apps Script |

Они сохраняются только в `SharedPreferences` на телефоне и не попадают в
публичный Release. Рядом есть кнопка **🩺 Статус ключей** — она показывает,
откуда ключ взят (с устройства или из старой сборки), и последние 4 символа.

> Старые сборки, где ключи всё ещё были в `BuildConfig`, продолжат работать:
> приложение сначала берёт сохранённый ключ, а потом fallback к встроенному.
> На Render менять ничего не надо — сервер проверяет тот же самый ключ.

### Курс валют

Донаты в EUR/USD/KZT больше не умножаются на `90`. Приложение раз в час берёт
курс с `open.er-api.com`, кэширует его и показывает в виджетах. Если сети нет —
используется ручной курс из **⚙️ НАСТРОЙКИ → 💱 Курс валют**. Кнопка
**🔄 Обновить курс** обновляет кэш принудительно.

## Сервер

```bash
npm install
npm start
```

Переменные окружения:

| Переменная | Обязательна | Описание |
|---|---|---|
| `PORT` | нет | Порт HTTP/WebSocket (по умолчанию `3000`) |
| `TIKTOK_ENABLED` | нет | `true`, чтобы включить подключение к TikTok LIVE |
| `TIKTOK_USERNAME` | нет | Аккаунт по умолчанию, без `@` |
| `ACCOUNT_SWITCH_KEY` | нет | Ключ для `POST /switch-account` |
| `TEST_EVENT_KEY` | нет | Ключ для `/test-gift` и `/test-donation` |
| `DONATIONALERTS_TOKEN` | нет | Токен DonationAlerts |

Эндпоинты: `GET /`, `GET /health`, `POST /switch-account`,
`GET /test-gift?key=...`, `GET /test-donation?key=...`, `WS /events`.

## Структура

```
app/src/main/java/com/livegiftstudio/
  MainActivity.java     — весь UI: меню, каталог подарков, звуки, настройки
  OverlayService.java   — foreground-сервис: WebSocket, оверлей, звуки, TTS
app/src/main/res/drawable — картинки подарков (webp)
app/src/main/res/raw      — звуки подарков (wav)
server.js                 — сервер событий
```
